# Perfil Compose con pruebas

Proyecto de ejemplo para la Investigación 2 de DSM441. La aplicación demuestra funciones `@Composable`, estado, recomposición, layouts, modificadores, Material 3 y pruebas de interfaz.

## Abrir y ejecutar

1. Descomprime el ZIP.
2. Abre Android Studio.
3. Selecciona **Open** y elige la carpeta `PerfilComposePruebas`.
4. Espera a que termine **Gradle Sync**. Si Android Studio solicita instalar el SDK 35, acepta la instalación.
5. Crea o selecciona un emulador Android.
6. Pulsa **Run app**.

## Ejecutar las pruebas

1. Abre `app/src/androidTest/java/sv/edu/udb/perfilcompose/PantallaPerfilTest.kt`.
2. Asegúrate de que el emulador esté iniciado.
3. Pulsa el triángulo verde ubicado junto a la clase `PantallaPerfilTest`.
4. Selecciona **Run PantallaPerfilTest**.
5. Comprueba que las tres pruebas aparezcan en color verde.

También puedes hacer clic derecho sobre la carpeta `androidTest` y seleccionar **Run Tests in...**.
